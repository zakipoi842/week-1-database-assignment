# school_management
# SQL Assignments — Zakariye

A collection of weekly SQL assignments for the database course.

## Structure

| Week | Topic | File |
|------|-------|------|
| 1 | MySQL Database Fundamentals | `week1/answer.sql` |
| 2 | SQL Queries (SELECT, WHERE, ORDER BY, LIMIT) | `week2/answer.sql` |
| 3 | Transactions & Aggregate Functions | `week3/answer.sql` |

## How to Run

```bash
# Week 1
sudo mysql < week1/answer.sql

# Week 2 (requires `sales` database imported first)
sudo mysql < week2/answer.sql

# Week 3
sudo mysql < week3/answer.sql
